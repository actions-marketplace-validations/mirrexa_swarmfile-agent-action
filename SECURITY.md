# Security Policy

## Reporting a vulnerability

Please report suspected security issues privately, not in a public issue or
pull request. Use GitHub's **Report a vulnerability** (Security → Advisories →
Report a vulnerability) on this repository, or email security@swarmfile.com if
the advisory flow is unavailable. Include a description, a reproduction, and
the affected revision/tag if you can.

We aim to acknowledge a report within 3 business days and to keep you updated
as we triage and fix. Please give us reasonable time to ship a fix before any
public disclosure.

## Scope notes

- This repository is a source snapshot of a component of Swarmfile; the hosted
  hub itself is out of scope for this repository's advisories.
- Never include real tokens, keys, or customer data in a report, issue, or
  patch. Redact them.
